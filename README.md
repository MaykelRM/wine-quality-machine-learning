### Combinação dos datasets
Neste trabalho, foram utilizados dois arquivos do conjunto Wine Quality: um contendo informações sobre vinhos tintos e outro sobre vinhos brancos. Os dois datasets foram combinados em um único conjunto de dados para ampliar a quantidade de amostras utilizadas na análise exploratória e no treinamento dos modelos de Machine Learning.

Também foi criada a variável-alvo `tag` para classificar os vinhos em duas categorias de qualidade, conforme o critério definido no tratamento dos dados.
